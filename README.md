## Stack
* MongoDb
* Nest

# Ejecutar en desarrollo
 1. Clonar el repositorio

 2. Ejecutar el comando 
 ```
  yarn install
 ```

 3. Instalar Nest CLI
 ```
  npm i -g @nestjs/cli
 ```

 4. Levantar la BD
 ```
  docker-compose up -d
 ```
